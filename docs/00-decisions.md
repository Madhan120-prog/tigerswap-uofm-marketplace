# TigerSwap Decisions Log

## Product scope
- Demo MVP, but all flows must work end-to-end (no fake screenshots-only demo).
- Team: 2 developers.
- MVP focus: Marketplace only (no peer mentoring / events for MVP).
- Timeline: 3 weeks.

## Platform / Stack
- Web-first, mobile-first UI.
- Framework: Next.js (App Router) + TypeScript.
- Reason: fastest to ship, easy demo, stable deployment options.

## Authentication
- Strictly UofM verified: only @memphis.edu emails allowed.

## Development process
- main branch stays stable and runnable.
- Work is tracked as GitHub Issues (stories) + Project board.
- Feature branches per story → PR → merge to main.
